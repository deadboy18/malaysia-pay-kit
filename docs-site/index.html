What's Inside

One package, zero research time.

🏦 Bank Data

46 banks with IBG, BIC, routing ID, acquirer ID, FPX IDs, and account number formats per type. Conventional, Islamic, and digital banks.

📱 E-Wallets

TNG, GrabPay, Boost, ShopeePay, BigPay, and more. Proxy vs account pay flags, DuitNow BIC codes, app store links.

✅ Validators

Account numbers, phone numbers (+60 normalization + carrier detection), MyKad/NRIC (birth date + state + gender), postcodes, SSM registration.

📊 QR Decoder

Decode DuitNow QR strings into structured data. EMV TLV parser, CRC16 validation, static QR generator. Based on natsu90's research.

🔢 Response Codes

500+ codes across FPX, Visa/MC, DuitNow, GrabPay, TNG, ShopeePay, Riipay, e-Mandate, and batch processing.

📄 Documentation

Complete PayNet docs in markdown, community QR research, bank code cross-reference, account formats, FPX reference, and curated resource links.

Quick Example

Works with require() or import.

example.js
const MY = require('malaysia-pay-kit'); // Look up any bank MY.getBankByBic('MBBEMYKL'); // → Maybank MY.getBankByFpx('MB2U0227'); // → Maybank // Validate account number MY.validateAccount('maybank', '512345678901'); // → { valid: true, bank: 'Maybank', possibleTypes: ['current','savings','loan','hirePurchase'] } // Validate phone + detect carrier MY.validatePhone('0123456789'); // → { valid: true, normalized: '+60123456789', carrier: 'Maxis', type: 'mobile' } // Validate MyKad MY.validateIC('900101-14-5678'); // → { valid: true, birthDate: '1990-01-01', state: 'Kuala Lumpur', gender: 'female' } // Decode DuitNow QR MY.decodeDuitNowQR(qrString); // → { type: 'static', isDuitNow: true, merchant: {...}, amount: 10.50, crcValid: true }
